# نهمیتو — خلاصه کتاب‌های کلاس نهم 📘

خلاصهٔ درس‌به‌درس همهٔ کتاب‌های پایهٔ **نهم متوسطه اول** به همراه **نکات کلیدی** و **سوالات احتمالی امتحان با پاسخ تشریحی**، در یک وب‌سایت فارسیِ راست‌چین که با **GitHub Pages** اجرا می‌شود.

## ✨ امکانات

- ۱۲ کتاب درسی رسمی (ریاضی، علوم، فارسی، عربی، زبان انگلیسی، مطالعات اجتماعی، قرآن، پیام‌های آسمان، آمادگی دفاعی، کار و فناوری، فرهنگ و هنر، نگارش)
- خلاصهٔ جزء به جزءِ درس‌ها + نکات کلیدی + واژگان مهم
- صدها سوال احتمالی امتحان با پاسخ تشریحی (قابل باز و بسته شدن)
- جستجوی سریع در متن همهٔ درس‌ها
- نشانه‌گذاری «این درس را خوانده‌ام» و نوار پیشرفت مطالعه (ذخیره در مرورگر)
- حالت تاریک/روشن، طراحی واکنش‌گرا (موبایل و دسکتاپ) و امکان چاپ / خروجی PDF

## 🚀 اجرا روی GitHub Pages

سایت استاتیک است و آماده انتشار است؛ کافی است Pages را **یک‌بار** فعال کنید (دو روش):

### روش ۱ — ساده‌تر (انتشار از شاخه، بدون نیاز به Actions)
1. در مخزن: **Settings → Pages**
2. در بخش **Source** گزینه **Deploy from a branch** را انتخاب کنید.
3. شاخهٔ `arena/01a0dd13-class` و پوشهٔ `/ (root)` را برگزینید و **Save** بزنید.
4. پس از چند دقیقه سایت روی `https://javadxpro.github.io/class/` بالا می‌آید.

### روش ۲ — با GitHub Actions
1. در **Settings → Actions → General** گزینه **Allow all actions and reusable workflows** را فعال کنید.
2. در **Settings → Pages** بخش **Build type** را روی **GitHub Actions** بگذارید.
3. هر `push` (یا اجرای دستی workflow از تب Actions) سایت را مستقر می‌کند؛ فایل استقرار: `.github/workflows/pages.yml`.

## 💻 اجرای محلی

کافی است پوشهٔ سایت را با یک وب‌سرور استاتیک باز کنید:

```bash
python3 -m http.server 8080
# سپس http://localhost:8080 را باز کنید
```

## 🗂 ساختار

```
index.html            صفحه اصلی (فهرست کتاب‌ها + جستجو)
book.html?b=math      صفحه هر کتاب (فهرست درس‌ها، خلاصه، سوالات)
assets/css/style.css  استایل‌ها
assets/js/app.js      منطق سایت (جستجو، پیشرفت، تم)
assets/js/meta.js     فهرست کتاب‌ها
assets/js/data/*.js   محتوای درس‌ها (خلاصه، نکات، سوال و جواب)
```

## 📌 یادداشت

محتوای این مجموعه «خلاصه‌های آموزشی» است و بر اساس سرفصل‌های کتاب‌های درسی رسمی سازمان پژوهش و برنامه‌ریزی آموزشی تهیه شده است؛ برای مطالعهٔ کامل، کتاب درسی مرجع اصلی است.
